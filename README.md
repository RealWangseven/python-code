## 🌱 我想说的是

**先理解，再动手，最后回顾。**

尝试自己完成练习，遇到问题时查资料、调试和提问。除了记录“做出来了什么”，也记录“为什么这样写”和“哪里还没弄懂”。

**📝 每次学习后的回顾**

  


- 今天学会了什么？
- 哪段代码能够独立写出来？
- 遇到了什么错误，原因是什么？
- 下次需要继续解决什么？
